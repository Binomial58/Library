# Library

競技プログラミング用ライブラリ。

## 構成

- [cpp/](./cpp/) — C++ ライブラリ本体。各 `.hpp` に対応する `.md` で仕様を記述（一覧は [cpp/README.md](./cpp/README.md)）
- [python/](./python/) — Python ライブラリ
- [vendor/](./vendor/) — 外部ライブラリ（[ac-library](https://github.com/atcoder/ac-library) 等）

## 利用方法

解答リポジトリ（Competitive-Programming）からはシンボリックリンク `library -> ../Library` 経由で参照し、必要なコードを解答ファイルへ貼り付けて使う。
